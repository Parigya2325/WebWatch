# WebWatch

## Intelligent Website Monitoring and Security Analysis Tool

### Project Description

WebWatch is a real-time website monitoring system that checks:

- Website Availability
- Response Time
- SSL Certificate Expiry
- Security Headers
- Uptime Statistics

The project is built using:

- Python
- Flask
- SQLite
- Bootstrap
- APScheduler
- Requests
- Plotly
